Supabase do site oficial

O caminho que fizemos juntos. Use como referência se precisar refazer.

Criar a organização e o projeto

Organização Bistrô Connect (Free) › projeto site-oficial › região São Paulo › “Automatically expose new tables” desligado › “Enable automatic RLS” ligado.

Rodar o SQL

SQL Editor › New query › colar ebistro-banco-completo.sql › Run › Run query no aviso › “Success”.

Criar o seu usuário

Authentication › Users › Add user › Create new user › e-mail, senha e “Auto Confirm User”.

Liberar como administrador
insert into public.admins (user_id)
select id from auth.users where email = 'adilsonrutes@gmail.com';
Fechar o cadastro

Authentication › Sign In / Providers › desligar “Allow new users to sign up” › Save changes.

Conectar o painel

Settings › API Keys › aba Legacy › copiar a anon › colar em seusite/admin/ › Testar e conectar › Baixar config.js › subir em public_html/assets/.

Ativar as 2 etapas

Entrar no painel › ler o QR Code com o Google Authenticator › digitar os 6 números.

!
Falta fazer neste projetoAuthentication › URL Configuration › Site URL: trocar http://localhost:3000 pelo endereço do seu site e salvar. Depois, mandar um contato de teste pelo site e conferir em Leads.

08

Segurança

O que já protege o sistema, sem você precisar fazer nada.

  • Login em 2 etapas nos painéis, saída após 30 minutos, sessão só na aba aberta
  • Regras no banco: visitante só cria lead ou pedido e não lê nada; uma loja nunca vê outra
  • Preço de cada pedido conferido no banco (mexer no navegador não adianta)
  • Limites contra robôs em leads e pedidos
  • HTTPS obrigatório, arquivos internos bloqueados, painel fora do Google
  • Proteção CSP: script injetado por invasor não roda
!
Regras de ouroNunca compartilhe a chave service_role/secret, a senha do banco ou o QR Code · senha forte e diferente em cada serviço · 2 etapas também na Hostinger, Supabase, GitHub e e-mail · a cada 3 meses, exporte os leads em CSV e revise quem é administrador.

Como fazer atualizações

Quatro tipos de mudança. Comece sempre pela mais simples.

Tipo 1 · dia a dia

Pelo painel

Leads, orçamentos, metas, cardápio, preços, fotos, horários, equipe. Aparece na hora, sem Hostinger.

Tipo 2 · configuração

Editar o config.js

WhatsApp, Pixel ou chaves: Hostinger › assets/config.js › Editar › mudar só o que está entre aspas › Ctrl+F5.

Tipo 3 · versão nova

Novo zip do site

Quando houver melhorias no sistema. Siga os passos abaixo.

Tipo 4 · banco

Arquivo .sql

Supabase › SQL Editor › colar › Run. Os arquivos do projeto podem rodar de novo sem perder dados.

Passo a passo de uma versão nova (tipo 3)

Faça um backup

Gerenciador de Arquivos › selecione o conteúdo de public_html › Compactar › baixe o zip para o computador.

Guarde o seu config.js

Baixe public_html/assets/config.js. O zip novo vem com um config.js vazio.

Suba e extraia o zip novo

Em public_html, aceitando substituir os arquivos.

Devolva o seu config.js

Para public_html/assets/. Se aparecer config1.js, apague o vazio e renomeie o config1.js para config.js.

Teste

Ctrl+F5 no site e faça a lista da próxima página.

!
Se algo der erradoExtraia o zip de backup em public_html e tudo volta como estava. Nunca rode drop table ou delete from no Supabase sem exportar os dados antes.

Testes e pedidos de mudança

Depois de qualquer atualização, confira esta lista.

  • O site abre no computador e no celular, com imagens e sem rolar para o lado
  • Os botões de WhatsApp abrem com o número certo
  • Formulário: enviar um contato de teste e ver o lead no painel
  • Painel: entrar com e-mail, senha e código; abrir Leads e gerar um orçamento em PDF
  • Lojas: fazer um pedido de teste, ver no painel e abrir o link de rastreio

Para pedir uma mudança ao Claude ou a um programador

Repositório: customersucess26-cell/Command-AI

Problemas e soluções

Os casos mais prováveis e o que fazer em cada um.

ProblemaO que fazer
Painel pede “Conectar o painel”Conferir se assets/config.js tem a supabaseUrl. Ou conectar pela tela e baixar o config.js.
Leads do site não chegamDeixar só assets/config.js (sem config1.js), com URL e chave; Ctrl+F5.
“Sua conta não tem acesso”Rodar de novo o insert into public.admins com o seu e-mail.
Perdi o celular do autenticadorNo SQL Editor, rodar o comando abaixo e entrar de novo (aparece um QR novo):
delete from auth.mfa_factors where user_id =
 (select id from auth.users
  where email = 'adilsonrutes@gmail.com');
Esqueci a senhaSupabase › Authentication › Users › seu usuário › “Send password recovery” (precisa do Site URL configurado).
Página branca no iPhoneAbrir pelo endereço do site no Safari ou Chrome, não pela pré-visualização de arquivo.
Imagens não aparecemExtrair o zip inteiro dentro da pasta certa, sem subpasta extra.
Supabase pausadoNo plano gratuito ele pausa após cerca de 1 semana sem uso: entrar e clicar em Restore. Com clientes reais, considerar o plano pago.
Autenticador mostra “localhost”Renomear a conta no app e configurar o Site URL (capítulo 5).
